# Vane 1 rc1 (pilot setup on Granite R2 97m) on nai-bench v1 dev – 2026-11-24

**PROVISIONAL.** v1 **dev split only** (47 answerable questions), no item human-reviewed, one run each. The 95 %
margin on MRR is roughly ±0.09; per-language and per-category groups (6–14 questions) are anecdotes.

- **rc1** = `ibm-granite/granite-embedding-97m-multilingual-r2` fine-tuned on the round-5 pilot pairs
  (`training/data/vane1-pilot/pairs-clean.jsonl`, 1,875 pairs; 0 nai-bench overlap and training guard re-checked
  2026-11-24), config [`training/configs/vane1-rc1-granite.json`](../../training/configs/vane1-rc1-granite.json):
  seed 13, 1 epoch, batch 64, lr 2e-5, max length 256, 1 mined hard negative. 1,381 rows survived mining, 22 steps,
  13 s on the RX 7900 XTX. Saved at `training/runs/vane1-rc1/model` (local, not exported, not published).
- **Held-out pilot pairs** (5 %, 88 pairs, same distribution as training): MRR@10 0.485 → 0.510, Hit@1 0.375 → 0.386.
- **Harness:** `evals/embeddings/dense_eval.py` (nAI's chunks of the v1 corpus, best chunk per file). Hybrid =
  file-level RRF (k = 60) of the dense ranking with nAI's own BM25 ranking (`dense_eval.py bm25` / `fuse`). Check
  of the approximation: for plain Granite it gives MRR 0.843 / Hit@5 0.894 against nAI's real hybrid run 0.834 /
  0.915 ([v1-dev-granite](v1-dev-granite-2026-11-23.md)); BM25 alone matches nAI exactly (0.842 / 0.894).
- Ranking files and the full table: `training/runs/vane1-pilot/eval/` (`rankings-*.json`, `scores-r9.md`).

## Reading

- **No measurable gain.** rc1 moves answers inside the top 5 (Hit@1 +0.02, cross-language MRR +0.02, hybrid MRR
  +0.01) and loses some at the edge (embedding Hit@5 −0.04: two questions drop out of the top 5, one
  cross-language, one table/OCR). Every difference is far inside the ±0.09 margin. The same 1,875 pairs lifted
  MiniLM a lot (0.444 → 0.613) because MiniLM was weak; Granite already sits near the ceiling of this data.
- **How far to trust it:** the pilot's synthetic documents (`corpus-v1`, household paperwork written by
  `mistral-small3.1`) are stylistically close to v1's fictional files (also invoices, letters, contracts of a
  family NAS). That closeness would inflate a gain, so a positive result here would have been weak evidence;
  a flat result is still informative: even with that domain advantage, 1,875 pairs don't help Granite. The
  held-out pilot pairs (+0.025 MRR@10, same distribution as training) show the run learned something, just
  nothing v1 dev rewards.
- **Consequence:** the data-scaling plan ([vane1-data-plan.md](../../docs/lab/vane1-data-plan.md)) is the next step;
  rc1 is a baseline, not a candidate. Hybrid fusion still loses Granite's cross-language gain (embedding Hit@5
  0.929 → hybrid 0.643): fusion weights matter more than this fine-tune (queued).
